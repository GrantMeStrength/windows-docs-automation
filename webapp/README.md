# Windows Documentation Generator - Web App Demo

## Quick Start

1. **Open the app:**
   ```bash
   open index.html
   ```
   Or double-click `index.html` in Finder

2. **Try it out:**
   - Fill in the form with any test data
   - Click through the workflow
   - See how documentation gets generated!

## What This Demonstrates

This is a **functional prototype** showing the complete workflow:

1. **Intake Form** - Minimal user input (5 fields)
2. **AI Planning** - Analysis and documentation plan
3. **Content Generation** - Creating all docs (simulated)
4. **Quality Validation** - Automated quality scoring
5. **Pull Request** - Auto-created with validation report

## Features

- ✅ **No build required** - Pure HTML/JavaScript
